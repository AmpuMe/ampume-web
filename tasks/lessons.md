# Lessons Learned

## Image Generation/Editing
- **ALWAYS visually review generated/edited images before committing.** Read the output image file and verify it matches the spec. Don't just trust that the API did what you asked.
- When editing images with Nano Banana, verify the actual output changed from the input. The API can silently fail or produce minimal changes.
- Don't push image work without verifying the pixels are correct.
